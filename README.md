# 李天宇错题本

手机入口：https://zxtt1998.github.io/tianyu-error-notebook/

## 两个科目

- 安全技术：5套卷，239道红笔选择题错题，原卷答案、解析与配图。
- 其他安全专业实务：3套卷，26道红笔选择题错题，以及全部9道案例简答题，共40个小问。

实务第1套收录10道选择题和3道案例（13小问）；第2套没有红笔标记，仅收录3道案例（13小问）；第3套收录16道选择题和3道案例（14小问）。红笔标记按题目位置逐页核对，题目和参考答案从原卷及卷末提取。

## 作答

选择题单选后自动进入下一题，多选手动确认；选项完全一致才算答对。简答题逐问填写，文字自动保存。本轮完整作答后可提交，也可以直接结束作答查看已答部分的答案与解析。未答题和空白小问不判错、不显示参考答案。

选择题累计答错次数在提交时记录一次。简答题对照参考答案手动标记“已掌握／需复习”，每轮每小问记录一次需复习次数；修改本轮自评会相应调整本轮记录，刷新不会重复计数。已结束的练习可以查看结果，也可重练错题与需复习案例。

“下次继续”会暂存答案、文字和位置。两科使用独立存储键，原安全技术的存储键保留，迁移入口不会清除原来进度。首页和两科之间可以自由切换；同一设备同一浏览器可继续。跨设备继续请使用同一个专属同步链接；清除浏览器数据后重新打开专属链接可取回已同步的记录。

## 疑问、笔记与同步

答题页和答题卡可标记／取消疑问，疑问标记不会影响评分。两科题库首页显示累计已做、未完整作答和疑问题目数量，并提供练习未做题、练习疑问题与题目记录入口。

结束后每道题都可以编辑自己的笔记，实务每个简答小问也有笔记框。输入自动保存，题目记录中可再次编辑笔记。

使用同一个专属同步链接连接手机和电脑，不需要注册或登录账号。链接在浏览器中自动保存；页面自动同步，并显示同步状态。断网时本机保存，联网后补同步。不同题目和不同小问分别合并；同一段内容由最后一次编辑覆盖。

此前仅保存的当前轮进度及已有累计次数会迁移，已丢失的更早正确作答历史不能补回。从本版本起累计记录每道题的作答状态。

## 发布与数据

公开网址：https://zxtt1998.github.io/tianyu-error-notebook/

- `index.html`：两科入口。
- `technical/index.html`：安全技术。
- `practical/index.html`：其他安全专业实务。
- `learning.js` / `learning.css`：学习记录、疑问、笔记与同步界面。

复用用户现有的 Supabase Free 项目，未升级付费套餐。使用自定义256位能力密钥鉴权、浏览器端 AES-GCM 加密、数据库版本号条件更新；数据表启用 RLS，并撤销浏览器角色的直接访问权限。Edge Function 在确认密钥后访问对应的唯一记录。密钥只通过用户的专属链接在自己的设备间传递，不放在公开 GitHub 文件中。云端保存加密数据，图片按需加载并缓存在设备上。

只发布题库和程序源代码。个人作答、标记与笔记不会提交到公开 GitHub 仓库。答题和同步不调用AI服务。专属同步链接绑定私人记录，应由用户自己保存。GitHub Pages 的 `.nojekyll` 保留。

## 加载与缓存

首屏所需脚本与样式包含在页面内，不等同步服务响应即可练习。题目图片按需加载。成功打开后，Service Worker 缓存两个科目页面和已加载图片；同步断网时保留本机记录，恢复网络后重试。首次访问仍需要能访问 GitHub Pages。

## 完整离线下载

顶部“离线下载”可主动下载两科页面及全部36张题目和解析配图，显示缓存数量、总大小和完成状态。每台设备分别下载，失败后重新点击会继续补齐缺失文件。离线答题和笔记保存在当前浏览器，恢复网络后按原同步规则补同步。浏览器清理数据后需要重新下载。

按原卷红笔批改新增45道错题（33单选、12多选），标准答案和解析来自卷末。新增题目图3张、解析图1张，安全技术共239题。原有题目ID、存储键和同步规则保持兼容，旧进度、笔记和累计答错次数继续保留。离线用户更新后需重新点击完整下载，以补齐新增题库。

## PDF 手写练习与本地批改

顶部“PDF手写练习”进入独立页面。按科目、套卷、题型、当前练习、累计错题或疑问标记筛选导出。选择题固定答题框并留笔记区；案例材料和各小问分开留书写空间。可选择把原卷参考答案与配图放在末尾。PDF中文以高分辨率图像嵌入。

在深色固定框内勾选或涂黑，保存后导入；淡笔迹和单选多框需人工确认，可逐题修改识别结果，再进行严格多选判分。仅支持本工具导出的PDF；不要改变页数、顺序或尺寸。元数据被移除时同时选择原始PDF。简答自评。PDF文件在本机处理，不上传、不调用AI；PDF记录独立保存于本机，网页进度、同步、笔记和累计次数不受影响。更新后重新完整离线下载，可离线导出和批改。

## 作答与计分

开始练习前选择“本轮结束后显示”或“每题确认后立即显示”；逐题模式单选选择后显示答案并停留，多选点确认后显示，已确认题不能修改，案例简答继续在本轮结束后自评。选项长按550毫秒变灰排除，再次长按恢复，也可清除本题排除。排除不等于作答，排除已选项会取消该选择；排除与已确认状态随进度同步。单选全对1分；多选全对2分，少选且无错选每项0.5分，错选和空白0分。结果展示本轮选择题总分和每题分数，原正确率及累计未全对次数仍按完全答对统计。PDF批改同样显示考试分数。

## PDF按套卷导出

PDF页面使用可见套卷单选卡片，技术第1至5套、实务第1至3套及全部套卷均可选择；显示每套题数和当前范围。每个科目记住上次选择。加载期间禁用导出，快速切换科目以最后一次选择为准；加载失败可重试，不会把其他科目的旧数据当作当前数据导出。导出条件变化会隐藏旧下载链接，避免下载错套卷。
